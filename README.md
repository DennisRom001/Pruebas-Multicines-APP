# Pruebas Automatizadas Móviles en Android (Appium + Pytest)

Este repositorio contiene la automatización de pruebas end-to-end para la aplicación móvil de Multicines en la plataforma Android, utilizando **Appium**, **Python** y **Pytest**.

## 🛠️ Tecnologías y Herramientas
- **Lenguaje:** Python 3
- **Framework Mobile:** Appium (Appium-Python-Client)
- **Driver Mobile:** UiAutomator2
- **Framework de Pruebas:** Pytest
- **Inspección de Elementos:** Appium Inspector

## 📌 Cobertura de Pruebas
- Validación del flujo de inicio de sesión (Login) en la app móvil.
- Manejo de fixtures de prueba y configuración remota del Driver en `conftest2.py`.
